# M00-T01 – Khung dự án

## Kế hoạch
1. Khởi tạo `package.json` với dependency `ws`, scripts: `start`, `dev`, `test`.
2. Tạo `.gitignore` chặn `node_modules/` và `logs/`.
3. Tạo thư mục `shared/`, `server/`, `client/`, `logs/`.
4. Tạo `server/server.js`: phục vụ file tĩnh (`client/`, `shared/`), hỗ trợ cờ `--port`, in danh sách IP khi khởi động (nêu rõ IP Radmin 26.x.x.x nếu có).
5. Tải font `VT323.ttf` vào `client/fonts/`.
6. Tạo `client/style.css` nạp font `@font-face VT323`, thiết lập 3 lớp hiển thị (`worldCanvas`, `uiCanvas`, `#ui-root`).
7. Tạo `client/index.html` với đủ 3 lớp và nạp các thẻ `<script>` theo đúng thứ tự quy định.
8. Tạo các file `shared/*.js` (từ 00 đến 21) dạng stub chuẩn UMD/global, có comment tiếng Việt ở đầu file.
9. Tạo các file `client/js/*.js` (từ 00 đến 10) đăng ký namespace vào `window.OP`, có comment tiếng Việt ở đầu file.
10. Trong `client/js/10-main.js`, thực hiện `OP.GAME.boot()`, vẽ chữ "OP-BR READY" bằng font VT323 trên `uiCanvas`.
11. Cài đặt dependency `ws` bằng npm.
12. Chạy `node --check` kiểm tra cú pháp tất cả file JS.
13. Khởi động server, kiểm tra truy cập `http://localhost:8080`, kiểm tra hiển thị và console.
14. Chạy checklist kiểm tra chất lượng (double check) và cập nhật báo cáo.

## Đã làm
1. Cập nhật quy định Git và quy định dấu vết vào mục 2 của `00-QUY-TRINH-AI.md`.
2. Khởi tạo `package.json` và cài đặt `ws@8.18.0`.
3. Tạo `.gitignore` bỏ qua `node_modules/` và `logs/`.
4. Viết `server/server.js` sử dụng Node.js module `http`, `path`, `fs`, `os` và `ws`. Tự động parse các cờ dòng lệnh (`--port`, `--seed`, `--dev`, `--bots`, `--fast`, `--no-launch`, `--headless-test`), phục vụ file tĩnh và in danh sách địa chỉ IP (đánh dấu Radmin VPN nếu dải IP bắt đầu bằng 26.x.x.x).
5. Tải font pixel `VT323.ttf` vào `client/fonts/VT323.ttf`.
6. Viết `client/style.css` khai báo `@font-face VT323`, thiết lập 3 lớp canvas và DOM container pixelated theo tỉ lệ logic 480×270.
7. Viết `client/index.html` chứa 3 lớp hiển thị (`worldCanvas`, `uiCanvas`, `#ui-root`), overlay bắt lỗi `#error-overlay` và nạp đủ 38 file script theo đúng thứ tự bắt buộc.
8. Tạo toàn bộ 15 file trong `shared/` (`00-namespace.js` đến `21-mapgen.js`) chuẩn IIFE UMD/global, không dùng import/export/require/fetch, có comment tiếng Việt đầu file.
9. Tạo toàn bộ 23 file trong `client/js/` (`00-boot.js` đến `10-main.js`) đăng ký namespace vào `window.OP`, có comment tiếng Việt đầu file.
10. Triển khai `OP.GAME.boot()` trong `client/js/10-main.js`: tự động căn chỉnh tỉ lệ phóng to pixel theo số nguyên và render dòng chữ "OP-BR READY" màu trắng trên `uiCanvas` bằng font `32px VT323`.
