# M00-T03 – Bộ test

## Kế hoạch
1. Tạo `tools/requirements.txt` chứa thư viện Python `websockets`.
2. Cài đặt dependency Python: `pip install -r tools/requirements.txt`.
3. Tạo `tools/check_static.py`:
   - Quét toàn bộ file trong `client/` và `shared/` để tìm từ khóa cấm (`import `, `export `, `require(`, `fetch(`, CDN...).
   - Kiểm tra các file quy định trong `docs/CAU-TRUC-THU-MUC.md`.
   - Kiểm tra thứ tự thẻ `<script>` trong `client/index.html`.
   - Kiểm tra độ dài mỗi file (< 500 dòng) và comment tiếng Việt ở đầu file.
   - Chạy `node --check` toàn bộ file `.js`.
4. Tạo `tools/check_data.js`:
   - Nạp `shared/` qua Node.js (`globalThis.OP_SHARED`).
   - Kiểm tra các hằng số `CONST` và các enum `DMG`, `TIER`, `TILE`, `ENT`, `WATER`, `MSG`, `BTN`... đã được đóng băng và hợp lệ.
5. Tạo bộ test server trong `server/tests/`:
   - `server/tests/assert.js`: thư viện assert tự viết (không dùng framework ngoài).
   - `server/tests/constants.test.js`: test hằng số, enum, RNG.
   - `server/tests/run.js`: tự động tìm và chạy toàn bộ các file `*.test.js` trong `server/tests/`.
6. Cập nhật `server/server.js`:
   - Thêm xử lý WebSocket cơ bản cho message `join` và `ping` khi cờ `--dev` hoặc `--headless-test` được bật, để phục vụ smoke test.
7. Tạo `tools/smoke_test.py`:
   - Tự động bật server ngầm trên cổng test 8088.
   - Sử dụng `websockets` tạo 4 client kết nối, gửi `join`, kiểm tra nhận `welcome`, kiểm tra ping/pong.
   - Đảm bảo server hoạt động ổn định và tự dọn dẹp tiến trình server khi kết thúc test.
8. Tạo `tools/run_all.py`:
   - Lần lượt gọi 4 bước: `check_static.py` -> `check_data.js` -> `server/tests/run.js` -> `smoke_test.py`.
   - In kết quả PASS/FAIL tổng hợp.
9. Thử nghiệm cố tình thêm `import` vào một file client để kiểm tra `check_static.py` bắt được lỗi FAIL như yêu cầu.
10. Chạy Double Check lớn cho Milestone M00, viết `reports/M00-T03.md`, `reports/M00-TONG-KET.md`, cập nhật `docs/TIEN-DO.md`.

## Đã làm
1. Tạo `tools/requirements.txt` (`websockets>=12.0`) và cài đặt thành công thư viện.
2. Viết `tools/check_static.py` kiểm tra toàn bộ luật tĩnh: từ khóa cấm trong client/shared, thứ tự script trong `index.html`, giới hạn 500 dòng/file, comment tiếng Việt đầu file, và chạy `node --check` toàn bộ file JS.
3. Viết `tools/check_data.js` kiểm tra sâu cấu trúc dữ liệu `CONST`, `DMG`, `PHYSICAL`, `TIER`, `TILE`, `WATER`, `PHASE`, `STATUS`, `BOT_LEVEL`, `MSG`, `BTN`, `KEYS`, `RNG`.
4. Tạo `server/tests/assert.js` hỗ trợ so sánh sâu `deepStrictEqual`, `strictEqual`, `ok`, `throws` mà không dùng thư viện ngoài.
5. Viết test mẫu `server/tests/constants.test.js` kiểm tra tính toàn vẹn của CONST và tính xác định (deterministic) của RNG.
6. Viết `server/tests/run.js` tự động quét và chạy mọi test `*.test.js` trong `server/tests/`.
7. Cập nhật `server/server.js` xử lý bắt tay WebSocket cho message `join` (trả về `welcome`) và `ping` (trả về `pong`).
8. Viết `tools/smoke_test.py` tự động spawn server ở cổng 8088, tạo 4 client giả kết nối đồng thời qua `websockets`, gửi `join`, gửi `ping`, nhận `welcome`, nhận `pong` và dọn dẹp tiến trình an toàn.
9. Viết `tools/run_all.py` xâu chuỗi cả 4 bước kiểm tra với giao diện báo cáo tổng hợp.
10. Thực nghiệm kiểm chứng tiêu chí task: cố tình thêm `import foo from 'bar';` vào `client/js/01-net.js`, `check_static.py` lập tức báo FAIL chính xác dòng code vi phạm. Sau khi gỡ bỏ, toàn bộ test PASS trở lại.
