# M01-T01 – Lobby

## Kế hoạch
1. Xây dựng module `server/match.js`:
   - Máy trạng thái `PHASE.LOBBY`.
   - Quản lý danh sách người chơi trong lobby (id, name, colors, isHost, ws).
   - Xác định Host (người đầu tiên kết nối hoặc IP localhost).
   - Quản lý cấu hình bot: số bot (mặc định lấp đủ 32 hoặc cờ `--bots`), tỉ lệ botMix (40% easy / 40% normal / 20% hard).
   - Xử lý các message: `join`, `cfg`, `start`, `chat`.
   - Broadcast message `lobby` khi danh sách người chơi hoặc cấu hình thay đổi.
   - Broadcast message `chat` (lọc text <= 120 ký tự).
   - Chuyển pha sang `LAUNCH` / `PLAY` khi Host bấm Start.
2. Xây dựng module `server/net.js`:
   - Quản lý các WebSocket connection.
   - Parse và validate message JSON an toàn.
   - Rate limit input cơ bản.
3. Cập nhật `server/server.js` tích hợp `net.js` và `match.js`.
4. Viết unit test trong `server/tests/lobby.test.js`:
   - Test kết nối client đầu tiên nhận isHost = true.
   - Test kết nối client thứ hai nhận isHost = false, nhận danh sách lobby có cả 2 client.
   - Test cập nhật cấu hình bot từ Host.
   - Test broadcast chat.
5. Cập nhật client:
   - `client/js/01-net.js`: Tự động kết nối WebSocket, đăng ký handlers cho `welcome`, `lobby`, `phase`, `chat`.
   - `client/js/07a-ui-lobby.js`: Giao diện lobby trong `#ui-root` gồm:
     - Form nhập tên người chơi (mặc định Hải tặc #id), chọn màu nón/áo/tóc.
     - Nút "Sẵn sàng" / "Tham gia".
     - Danh sách người chơi trong phòng (hiển thị màu, vương miện host).
     - Bảng điều khiển dành riêng cho Host: chỉnh số lượng bot, độ khó bot, nút "BẮT ĐẦU".
   - `client/js/07d-ui-chat.js`: Khung chat ở góc màn hình, gửi bằng Enter, hiển thị bằng `textContent`.
   - `client/style.css`: Style pixel art cho lobby và chat bằng font VT323.
6. Chạy `tools/run_all.py` kiểm tra tĩnh, data, unit test, smoke test.
7. Viết test giả lập 2 tab trình duyệt qua Chrome DevTools Protocol để đảm bảo 2 tab thấy nhau trong lobby.
8. Hoàn thiện report `reports/M01-T01.md`.
9. Commit & push theo quy định.

## Đã làm
1. Xây dựng `server/net.js` quản lý kết nối WebSocket, parse/validate JSON, giới hạn tần suất input.
2. Xây dựng `server/match.js` quản lý máy trạng thái `PHASE.LOBBY`, danh sách người chơi, chỉ định Host, cấu hình bot và broadcast tin nhắn chat.
3. Tích hợp `NetManager` và `MatchManager` vào `server/server.js`.
4. Viết `server/tests/lobby.test.js` kiểm tra toàn bộ luồng kết nối, chỉ định Host, Host đổi config và broadcast chat.
5. Cập nhật `client/js/01-net.js`: Quản lý kết nối WebSocket tới server, gửi nhận tin nhắn và dispatch tới các handler.
6. Cập nhật `client/js/07a-ui-lobby.js`: Tạo giao diện DOM lobby hoàn chỉnh, cho phép người chơi đặt tên, chọn màu nón/áo/tóc, hiển thị danh sách người chơi với nhãn `[HOST]` và bảng điều khiển Host (chỉnh số bot, bắt đầu trận).
7. Cập nhật `client/js/07d-ui-chat.js`: Tạo khung chat DOM ở góc màn hình, hiển thị tên và nội dung bằng `textContent` phòng chống XSS.
8. Bổ sung style pixel art phong cách One Piece trong `client/style.css`.
9. Cập nhật `client/js/10-main.js` khởi tạo lobby và chat khi khởi động game.
10. Tự động kiểm thử bằng 2 tab trình duyệt thật qua Chrome DevTools Protocol: xác nhận 2 tab kết nối thấy nhau trong danh sách phòng và chat qua lại thành công.
