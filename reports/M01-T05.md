## 2. Kết quả thực hiện

### A. Công cụ Stress Test (`tools/stress_test.py`)
- Khởi động server subprocess chế độ headless.
- 32 client kết nối đồng thời qua WebSocket, gửi thông điệp `join` với màu sắc và tên riêng biệt.
- Client #1 đảm nhận vai trò host gửi lệnh `start`.
- Đồng thời chạy 3 luồng bất đồng bộ trên mỗi client:
  1. `input_loop`: Gửi input bitmask ngẫu nhiên (W/A/S/D) và góc ngắm `aim` ở tần số 30Hz.
  2. `ping_loop`: Gửi ping định kỳ 2s.
  3. `recv_loop`: Nhận các gói `snap` (AOI) và `pong`, thống kê snapshot và RTT.
- Phân tích file log trong `logs/`, đọc dữ liệu `perf` định kỳ của server.
